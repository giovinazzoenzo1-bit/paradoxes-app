# Images à intégrer (dépôt de l'auteur)

Déposer ici les images générées (Gemini), directement depuis la photothèque
du téléphone : « Add file » → « Upload files ». AUCUN renommage nécessaire :
Claude reconnaît chaque image par son format et son contenu.

Ce dossier est HORS de `mobile/` : un dépôt ici ne déclenche PAS la
publication automatique. Après intégration (optimisée) dans
`mobile/assets/`, Claude vide ce dossier.
