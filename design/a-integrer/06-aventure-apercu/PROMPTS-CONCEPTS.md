# Aperçu de niveau : 3 concepts SOBRES et ÉPURÉS (03/10)

Demande de l'auteur : « faire des prompts avec différents concepts, sobre et épurée ».
Écran en PAYSAGE (comme l'Exploration). Éléments relevés dans le code (FighterSelectOverlay) : RETOUR ; en haut à droite Éléments, Griffes (+), énergie ;
titre ; « Ta puissance N · conseillée M » (vert/orange/rouge) ; l'adversaire (1 à 3 dans les chapitres suivants) ; « Ton équipe (à tour de rôle) » (œuf si vide) ;
« ⚡ Coûte 1 énergie (X/5 disponibles) » ; « Combattre » (« Deck vide » / « Plus d'énergie » + 📺 +1 et 💎 quand l'énergie est à 0 : états gérés par le code).

Joindre 3 images : IMAGE 1 = capture du MENU PRINCIPAL ; IMAGE 2 = capture de l'APERÇU actuel (en paysage) ; IMAGE 3 = capture du hub EXPLORATION (le Ponton céleste).
Une NOUVELLE conversation par concept. Dépôt (dans l'ordre 1, 2, 3) : https://github.com/giovinazzoenzo1-bit/paradoxes-app/upload/main/design/a-integrer/06-aventure-apercu/concepts
