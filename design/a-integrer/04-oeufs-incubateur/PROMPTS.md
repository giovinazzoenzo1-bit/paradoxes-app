## Dernier stade en 2 calques (27/09) — déposer dans `04-oeufs-incubateur/eclats`

Lien : https://github.com/giovinazzoenzo1-bit/paradoxes-app/upload/main/design/a-integrer/04-oeufs-incubateur/eclats

Joindre à Gemini l'image du DERNIER stade de l'œuf (« prêt »), puis :

**24. L'œuf seul (sans les éclats)**

```
Edit the attached egg image: remove ALL the small eggshell fragments floating around the egg, and keep ONLY the egg itself, exactly identical: same shape, same cracks, same colors, same light inside the cracks, same size and same position in the frame. Square 1:1 image. On a perfectly flat, uniform, pure magenta background (#FF00FF), no gradient, no texture, no vignette. No shadow, no glow and no light around the object. No text. Never use pink, purple or magenta on the object itself.
```

**25. Les éclats seuls (5, bien séparés)**

```
Using the same attached egg image, create ONLY 5 separate eggshell fragments that match this egg exactly (same shell color, texture, thickness and light as the egg's broken shell), without the egg. Spread the 5 fragments apart across the image, well separated from each other with empty space between them: they must never touch or overlap. Each fragment has a different shape and size, from small to medium, and is slightly rotated. Square 1:1 image. On a perfectly flat, uniform, pure magenta background (#FF00FF), no gradient, no texture, no vignette. No shadow, no glow and no light around the object. No text. Never use pink, purple or magenta on the object itself.
```
