```

# Série 2 (02/10) — l'auteur a gardé l'ALBUM DE CARTES (concepts/1790968948748.jpg)

Joindre 3 images : IMAGE 1 = menu principal ; IMAGE 2 = ta Collection actuelle ; IMAGE 3 = la maquette de l'Album gardée. Un prompt par concept, chacun dans une NOUVELLE conversation.

**4. L'Arbre aux nids**

```
