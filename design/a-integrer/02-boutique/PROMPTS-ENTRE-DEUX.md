# Objets « entre-deux » — prompts Gemini 98 à 109

**Mode d'emploi** : NOUVELLE conversation Gemini. Au prompt 98, joindre l'image de référence (la planche des icônes du Grimoire,
`grimoire/1790837933726.jpg`, déjà envoyée sous le nom « reference-style-v2 »). Puis 99 à 109 dans la MÊME conversation.

Déposer les 12 images ici : https://github.com/giovinazzoenzo1-bit/paradoxes-app/upload/main/design/a-integrer/02-boutique/grimoire
(l'envoi groupé inverse souvent l'ordre : les images sont identifiées par leur CONTENU). En attendant, le jeu affiche l'emoji.

```

No drop shadow, no glow and no light around the object. Never use pink, purple or magenta on the object itself.
```
