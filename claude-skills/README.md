# Skills Claude — Projet Paradox

Ces dossiers sont des **skills Claude** installables depuis le téléphone
(fichier `.skill` → bouton « Enregistrer le skill »).

| Skill | Se déclenche quand |
|---|---|
| `paradox-socle` | tout travail sur le projet — démarrage, interdits, publication, doc |
| `paradox-creatures` | ajout/design d'une créature, réponse Gemini collée, illustrations |
| `paradox-aventure` | écrans, carte, chapitres, décors, bug d'affichage ou de tap |
| `paradox-equilibrage` | toute valeur chiffrée — difficulté, dégâts, prix, gains, courbes |

`paradox-socle` s'applique en plus des trois autres, jamais à la place.

⚠️ Dossier volontairement placé **hors de `mobile/`** : un fichier modifié ici
ne déclenche pas la publication EAS Update.

Pour modifier un skill : éditer le `SKILL.md`, repackager, réinstaller.
